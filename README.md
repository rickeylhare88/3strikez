# 3STRIKEZ

Premium urban streetwear storefront — static site, deployed to GitHub Pages.

**Tagline:** MORE THAN CLOTHING. IT'S A LIFESTYLE.

## Structure
- `index.html` — home: cinematic boutique hero with tappable category hotspots, category grid, new arrivals
- `shop.html` — full catalog: search, sort (Featured / price / name), category filters
- `about.html` — brand story
- `contact.html` — contact (placeholder email `info@3strikez.com` — swap for the real one)
- `css/styles.css`, `js/app.js` — shared styles + storefront logic
- `assets/` — AI-generated photorealistic imagery (v1 set)

## Notes
- Cart is front-end only (localStorage). Size selection is required before add-to-bag.
- Checkout is intentionally disabled — labeled "coming soon". No payment flow is faked.
- Demo storefront: 12 products with launch pricing.
